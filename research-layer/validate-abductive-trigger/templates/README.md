# Templates and When to Use Them

Templates preserve real research records; they are not forms that must all be completed before starting. Begin with a candidate lens and raw materials without prior coding. null means unavailable/not applicable; existing project formats may be mapped.

| File | Purpose |
|---|---|
| [empirical-inputs.json](empirical-inputs.json) | Bind raw/existing materials, sources, and versions; existing coding paths are optional |
| [material-review.json](material-review.json) | Actual reading scope, unread/unreadable sources; not coding-completion metrics |
| [theoretical-explanations.md](theoretical-explanations.md) | Step 2: independent abstract literature arguments, mechanisms, and scope |
| [observable-implications.md](observable-implications.md) | Step 3: case predictions, reasoning, supportive/contrary criteria, saved before empirical search |
| [theory-observation-comparison.md](theory-observation-comparison.md) | Step 4: both sides of evidence for each prediction, including unmatched items |
| [assessment.md](assessment.md) | Researcher-facing observations, explanatory coverage, potential novelty, and candidate development |
| [episode.json](episode.json) | Episode metadata and raw input bindings; evidence_base is an optional legacy interface |
| [finding.json](finding.json) | Stable Finding ID and distinct Revision ID; empirical references may identify raw sources |
| [human-feedback.json](human-feedback.json) | Summary/source of feedback about an exact revision, not verbatim feedback |
| [event.json](event.json) | Append individual events to canonical History |
| [state-update-proposal.json](state-update-proposal.json) | Concrete State update proposal |
| [tred-adapter-config.json](tred-adapter-config.json) | Bind actual routing/schema/writer without guessed mappings |

Use Markdown for substantive analysis, JSON for Findings/feedback/proposals, and JSONL for History. Comparisons can complete without coding files or a shared coding evidence base. Missing critical empirical evidence may imply Unresolved/partial; absence of coding does not.
